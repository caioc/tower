The pull requests and tickets that need you, in the order to do them.

Tower is a macOS menu bar app. It puts your GitHub pull requests, Jira tickets and CircleCI pipelines in one queue, sorted by urgency. Open the panel, see what to do next, and click through to it.

brew trust wilsonfaustino/tap
brew install --cask wilsonfaustino/tap/tower-menubar

macOS 26 or later, with the GitHub CLI (gh) signed in. Signed and notarized by Apple. Latest release.

The cask is tower-menubar because tower is the Git client of the same name.

Six sections, in the order you act on them.

The order is fixed, so the top row is always the next thing to do. Tower hides a section with no items. When all of them are empty, the panel says "Clear skies".

  1. Fix

    Your open PRs with failing checks, and your failed CircleCI pipelines that have no PR.

  2. Review

    PRs that ask for your review. A direct request turns urgent after 24 hours. Dependabot and Renovate PRs collapse into one row per bot.

  3. Merge

    Your approved PRs with no failing checks.

  4. Tidy

    Your in-progress Jira tickets with no PR, or with a PR that has no reviewer.

  5. Watch

    Your running CircleCI pipelines that have no PR. A pipeline on hold for approval is urgent.

  6. Waiting

    Your other open PRs: drafts, and PRs that wait for review. Changes requested is urgent. Merged PRs leave the list.

The icon changes shape, not color.

You read the menu bar without opening the panel. Each state has its own shape, so it works in a light or dark menu bar and does not depend on color.

  • Cab Nothing is urgent.

  • 3

    Beacon and a count Three items need you: a review that waits, changes requested, or a pipeline on hold.

  • 2

    Filled cab and a count Two items to fix: failing checks or a failed pipeline.

Old data beats an empty panel.

Tower refreshes every 5 minutes, and every 2 minutes when all sources are offline. It keeps the last good result of each source on disk. When GitHub, Jira or CircleCI fails, the panel keeps the old rows and the header tells you their age.

Two tabs or one page.

Split shows a "Needs you" tab and a "Waiting" tab, with running pipelines pinned below both. Consolidated shows every section on one scrolling page. Pick one in Settings.

Set up in Settings

GitHub
Tower reads your token from gh auth token. No extra sign-in. To limit the queue to some owners, enter one organization or user login per line.
Jira optional
Enter your site URL, email and an API token, then click "Test connection".
CircleCI optional
Enter an API token and one project slug per line, like gh/org/repo.
Launch at login
Copy Tower to /Applications, then turn it on in Settings, General. It is off by default.

Three hosts. No analytics.

Tower calls api.github.com, your Jira site and circleci.com. It has no server and no account of its own. The GitHub token stays in memory. The Jira and CircleCI tokens stay in the macOS Keychain.

Put the queue in your menu bar.

brew trust wilsonfaustino/tap
brew install --cask wilsonfaustino/tap/tower-menubar

Homebrew loads a cask from a third-party tap only after you trust the tap, so run brew trust once.
